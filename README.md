# CouncilApp

**CouncilApp** — приложение для организации работы Совета обучающихся.

Приложение позволяет хранить информацию об участниках, вести посещаемость заседаний и планировать мероприятия через календарь.

Проект создаётся для практического использования Советом обучающихся.

## Возможности

### Главная

- цифровые часы;
- отображение ближайшего мероприятия;
- отображение ближайшего дня рождения участника;
- автоматическое обновление времени.

### Участники

Для каждого участника можно хранить:

- ФИО;
- класс;
- дату рождения;
- хобби;
- направление деятельности.

Также реализовано:

- добавление участников;
- редактирование данных;
- удаление участников;
- просмотр карточки участника;
- сортировка участников по классу и имени;
- проверка на дублирование участников.

### Посещаемость

Раздел позволяет:

- создавать заседания;
- выбирать дату заседания;
- добавлять описание обсуждения;
- редактировать информацию о заседании;
- удалять заседания;
- отмечать присутствие участников;
- хранить историю посещаемости.

Для каждого участника можно переключать состояние:

`— → + → - → —`

где:

- `+` — присутствовал;
- `-` — отсутствовал;
- `—` — статус не установлен.

### Календарь

В календаре можно:

- переключаться между месяцами;
- создавать мероприятия;
- выбирать дату мероприятия;
- добавлять фотографию;
- просматривать информацию о мероприятии;
- изменять название, дату и фотографию;
- удалять мероприятия.

Мероприятия отображаются непосредственно в календарной сетке.

## Хранение данных

Приложение использует **JSON-файлы** для локального хранения данных:

- `members.json` — участники;
- `calendar.json` — мероприятия календаря;
- `attendance.json` — посещаемость;
- `meetings.json` — заседания.

При запуске приложение создаёт отдельную папку `data` для хранения данных.

Также предусмотрено постоянное хранилище Flet для мобильной версии приложения.

## Адаптивность

Интерфейс учитывает размер экрана:

- **ПК** — боковая панель навигации;
- **планшет** — адаптированная навигация;
- **телефон** — нижняя панель навигации.

Размеры элементов, диалоговых окон и календаря автоматически изменяются в зависимости от размера экрана.

Приложение реагирует на изменение размеров окна, включая изменение ориентации устройства.

## Технологии

- **Python**
- **Flet**
- **JSON**
- **Git**
- **GitHub**

Дополнительно используются стандартные библиотеки Python:

- `asyncio` — обновление часов;
